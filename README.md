# 楕円曲線クエスト ― 仕様説明書

楕円曲線 **y² = x³ + ax + b** の「点の足し算」を、グラフを見ながら遊んで学ぶゲームです。
最終的には、楕円曲線暗号のしくみ（**P と Q = kP から k を求めるのは難しい**）を体験できるようになっています。

---

- pygame（または互換版の pygame-ce）

## 2. 画面と遊び方

タイトル画面のボタンは、**上から順に遊ぶと理解しやすい**ように並べてあります。

### ① グラフで体験しよう（自由に触る画面）

| 項目 | 内容 |
|---|---|
| 目的 | 点の足し算の作図を、アニメーションで見て理解する |
| 操作 | 曲線の上をクリックすると点を置けます。点はドラッグで動かせます |
| スライダー | a（−4〜3）と b（−3〜3）を 0.1 刻みで変えられ、曲線の形が変わります |
| モード「P + Q」 | P と Q を通る直線 → 3つ目の交点 ★ → 上下反転、を順に見せます |
| モード「2P」 | P での接線を使った足し算（P + P）を見せます |
| モード「kP」 | P, 2P, 3P, … と足していく様子を見せます（k は 2〜8） |
| 右のパネル | 今どの手順か（①〜④）を明るく表示し、点の座標も表示します |

指を離すたびに、アニメーションが最初から再生されます（約2.2秒）。

### ② グラフクイズ（全10問）

点 P, Q が示されるので、答えの点を候補 **A〜D** から選びます。計算は不要で、作図のルールだけで解けます。

| 問題の種類 | 問題文 | 正解 |
|---|---|---|
| 足し算 | P + Q はどれ？ | 直線の3つ目の交点 ★ を上下反転した点 |
| 2倍 | 2P はどれ？ | 接線の交点 ★ を上下反転した点 |
| 逆元 | −P はどれ？ | P を上下反転した点 |
| 無限遠点 | P + Q はどれ？（Q が P の真下） | O（無限遠点） |

- 「足し算」「2倍」の問題では、**★ そのもの**をわざと選択肢に混ぜてあります（よくある間違い）。選ぶと「最後にひっくり返そう」と教えてくれます。
- **得点** ＝（基本点 ＋ スピードボーナス）× コンボ倍率
  - 基本点: 100 点（ヒントを使うと 50 点）
  - スピードボーナス: 20 秒以内に答えると「残り秒数 × 3」点
  - コンボ倍率: 連続正解するごとに 1.0 → 1.2 → 1.4 … 最大 2.0 倍。間違えると 1.0 に戻る

### ③ 暗号クイズ：秘密の数 k を見破れ（全5問）★今回追加

点 P と、P を k 回足した点 **Q = kP** が示されます。**k はいくつ？** を当てるクイズです。

#### 暗号とのつながり
楕円曲線暗号では、**k が「秘密鍵」、Q = kP が「公開鍵」**です。
P と Q は誰でも見られますが、そこから k を求めるのはとても難しい。それを体験する問題です。

#### ヒント機能（総当たり）
- 「総当たりで次を計算する」ボタンを押すたびに、**2P → 3P → 4P → …** と1つずつ計算して作図を見せます。
- 計算した点が Q と重なれば、k が分かります。
- そのかわり、**1回押すごとに得点が 15 点下がります**。
- これは、暗号を破るために k を 1 から順に全部試す「**総当たり攻撃**」と同じです。

| ヒントの回数 | 0回 | 1回 | 2回 | 3回 | 4回 | 5回 | 6回 | 7回以上 |
|---|---|---|---|---|---|---|---|---|
| 正解したときの得点 | 100 | 85 | 70 | 55 | 40 | 25 | 10 | 10（最低点） |

不正解は 0 点です。答えは 1 問につき 1 回だけです。

#### 答えた後の画面
- P → 2P → 3P → … を点線でつなぎ、**一周して O に戻る**様子を見せます。
- 「位数」（O に戻るまでの回数）の説明と、暗号に関する**豆知識**を1つ表示します。
- 答えが「位数 − 1」のとき（Q が P の真上か真下にあるとき）は、そのことにも触れます。

#### 問題の作り方
1. 何問目かに応じて、使う点の位数を決めます（後の問題ほど位数が大きく、難しくなります）。

   | 問題 | 1問目 | 2問目 | 3問目 | 4問目 | 5問目 |
   |---|---|---|---|---|---|
   | 位数 | 5〜6 | 6〜7 | 7〜8 | 8〜9 | 9〜10 |

2. `special_points.py` から、その位数の「特別な点」を1つ選びます。
3. その点を m 倍した点を P にします（m は位数と「互いに素」な数）。こうすると、同じ曲線でも毎回ちがう問題になります。
4. k を 2〜(位数 − 1) の中から選び（最大 9）、Q = kP を計算します。
5. すべての点が見えるように、グラフの表示範囲を自動で合わせます。

#### なぜ「特別な点」を使うのか
ふつうの点は、P, 2P, 3P, … と足すとどんどん遠くへ飛び、画面からはみ出してしまいます。
一部の点は何回か足すと O（無限遠点）に戻り、同じ点をぐるぐる回ります。このような点を使えば、何倍しても画面の中に収まります。

## 5. プログラムのしくみ

### 5-1. ゲームループ（`main.py`）
ゲームは次の3つを **1秒間に60回** くり返して動いています。

```
① 入力を受けとる（クリック・キー） → scene.handle_event(event)
② 時間を進める（アニメーション）     → scene.update(dt)
③ 画面を描く                         → scene.draw(screen)
```

### 5-2. 画面（Scene）の切りかえ
- 画面は1つずつ「クラス」になっていて、すべて `ui.py` の `Scene` を元にしています。
- `main.py` の `SCENES` という表で、画面の名前とクラスを対応させています。
- 画面を切りかえるときは `app.goto("画面の名前")` と書きます。
  例: `app.goto("title")` → タイトル画面へ
- 情報を渡したいときは `app.goto("result", score=500, ...)` のように書きます。

### 5-3. 点の表し方（`curve.py`）
- ふつうの点は `(x, y)` というタプルです。例: `(3, 8)`
- 無限遠点 O は `None` で表します。

### 5-4. 足し算の計算（`curve.py` の `add()`）
作図の手順をそのまま式にしています。

1. 直線の傾き λ を求める
   - P ≠ Q のとき: λ = (y2 − y1) ÷ (x2 − x1)
   - P = Q のとき: λ = (3 × x1² + a) ÷ (2 × y1)（接線の傾き）
2. 3つ目の交点 ★ の x 座標: x3 = λ² − x1 − x2
3. ★ の y 座標を直線の式から求め、符号を反対にした点が答え

P と Q が真上・真下の関係なら、直線が縦になるので答えは O（`None`）です。
答えだけでなく、★ や傾きも `AddResult` にまとめて返すので、作図アニメーションに使えます。

### 5-5. 数学の座標と画面の座標（`graph.py` の `to_screen()`）
- 数学では**上**が y の正の向きですが、画面では**下**に行くほど数字が大きくなります。
- `to_screen()` が「数学の座標 → 画面のピクセル位置」の変換をしています。
- 表示する範囲（x_min〜x_max, y_min〜y_max）を変えると、拡大・縮小になります。
